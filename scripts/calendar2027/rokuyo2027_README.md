## 2. 規則
1. 旧暦(天保暦): 各月の1日 = 朔の日 (JST暦日)。月番号は、その月に含まれる中気で決める (雨水=1, 春分=2, 穀雨=3, 小満=4, 夏至=5, 大暑=6, 処暑=7, 秋分=8, 霜降=9, 小雪=10, 冬至=11, 大寒=12)。中気を含まない月は閏月 (前月の番号を引き継ぐ)。
2. 六曜 = (旧暦月 + 旧暦日) mod 6 → 0 大安 / 1 赤口 / 2 先勝 / 3 友引 / 4 先負 / 5 仏滅。閏月は引き継いだ月番号で計算 (2026-27は該当なし)。
   検算: 旧1月1日=先勝、旧7月1日=先勝、旧2月1日=友引、旧11月1日=大安、旧12月1日=赤口 (いずれも通説どおり)。
3. 2027年が使った旧暦月: 2026-12-09〜(11月) / 01-08(12月) / 02-07(1月) / 03-08(2月) / 04-07(3月) / 05-06(4月) / 06-05(5月) / 07-04(6月) / 08-02(7月) / 09-01(8月) / 09-30(9月) / 10-29(10月) / 11-28(11月) / 12-28(12月)。
4. 年末の注意: 12-28 から始まる月を「12月」とするには 2028-01-20頃の大寒 (令和10年暦要項) が前提だが、大寒は毎年1/20±1日で次の朔(2028-01-27頃)より前なので結論は動かない。**2027年の365日はいずれも令和10年暦要項の公表待ちの日はない** (公表後に念のため大寒日・1月朔のみ確認すれば十分)。
5. 朔が0時台で日付が際どい月: 2027-02-07 (0:56)。2026-10-11 (0:50)。外部サイトとも一致を確認済み。

## 5. サイト掲載用の注意書き案
> 六曜(大安・友引・先勝・先負・赤口・仏滅)は中国由来の暦注で、神道の教義や神社の祭祀とは関係がありません。国立天文台の暦要項にも掲載されない参考情報です。旧暦(朔と二十四節気)から算出しており、サイトによって扱いが異なる場合があります。日取りは神社の案内もあわせてご確認ください。

英語案: "Rokuyo (Taian, Butsumetsu, etc.) is a calendar notation of Chinese origin. It is unrelated to Shinto doctrine and is not published in the National Astronomical Observatory of Japan's official calendar. It is shown for reference only."
