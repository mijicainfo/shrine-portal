# 開運カレンダー2027 のデータ元と更新手順

`src/data/calendar2027.ts` と `src/data/rokuyo2027.ts` は **自動生成**（`node scripts/gen-calendar.mjs`）。手で編集しない。

## ファイル
| ファイル | 役割 |
|---|---|
| `compute.cjs` | 日干支・暦注（一粒万倍日・天赦日・寅/巳/己巳/甲子の日）の計算。`node compute.cjs <年>` が `all<年>.json` を出す |
| `extras.cjs` | 国立天文台・内閣府の公的発表（祝日・二十四節気・雑節・朔望）と、派生（初午・夏の土用の丑）を結合して `calendar2027.json` を出す |
| `calendar2027.json` | 全365日のタグ付きデータ（生成元） |
| `rokuyo.cjs` / `rokuyo2027.json` | 六曜と旧暦の月日。`rokuyo2027_README.md` に根拠と照合結果 |

## 出典
- **祝日**: 内閣府「国民の祝日について」https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html（国立天文台 暦要項 令和9年と照合。2027年は17祝日＋3/22振替休日）
- **二十四節気・雑節・朔望**: 国立天文台 暦要項 令和9年 https://eco.mtk.nao.ac.jp/koyomi/yoko/2027/rekiyou272.html / rekiyou273.html（令和8年2月2日発表）。自由利用、出典明記が望ましい
- **暦注（天赦日・一粒万倍日・己巳の日・寅の日・巳の日・甲子の日）**: **公的発表ではない慣習**。日干支（ユリウス通日から算出）と節月（二十四節気の「節」の当日から新しい月）で、民間暦の一般的な規則どおりに計算。ベストカレンダー ICS・ゼクシィ・JAL SKYWARD Plus と 2026/2027 を照合して不一致なし
- **六曜**: 国立天文台の朔・中気から旧暦を求めて計算。ベストカレンダー・便利ジャパンと365日すべて一致

## 毎年の更新（来年版を作るとき）
1. 2月初旬に国立天文台が翌年の暦要項を発表 → `extras.cjs` の祝日・節気・雑節・朔望の表を転記。
2. `node compute.cjs <年>` → `node extras.cjs`（年を差し替え）→ `node scripts/gen-calendar.mjs`。
3. ベストカレンダーの ICS（https://bestcalendar.jp/ical/<年>/…）と一致を確認してから公開。
4. 2028年分は暦要項 令和10年が未公表（2026-11-07時点）。六曜の12月末（2027-12-28〜31）は大寒と1月朔が確定すれば最終確認になる。

## 注意
- 節入りの日付切替（当日か翌日か）で結果が変わる日が2027年に4日ある（4/5・6/6・8/8・10/8）。外部サイトに合わせて「節入り当日から新しい月」。
- 神社の年中行事（大祓・七五三など）は未掲載。載せる場合は神社本庁サイトの本文で日付を確認してから。
